# RouteMind AI

An AI-powered field operations platform that helps organizations optimize field visits, plan routes, manage clients, and generate AI-assisted recommendations.

## Tech Stack

- Frontend: Next.js + React + TypeScript
- Backend: Node.js + Express + TypeScript
- Database: PostgreSQL
- ORM: Prisma
- AI: OpenAI-compatible API
- Maps: Google Maps / Mapbox
- Deployment: Docker
